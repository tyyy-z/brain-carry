Before you carry on.

Is this a new notes app?

BrainCarry is an Agent Skill, Markdown templates and local Python tools. It gives your existing assistants a workflow for personal context and shared knowledge. You keep using your own editor.

Do I need a cloud service?

For access across agents while your computer is off, the recommended setup is Engram Cloud + Obsidian. Each client needs authorization and read/write verification. Local-only Markdown is supported, but its files require the host to be available. BrainCarry itself is not a sync server.

Will it remember every chat?

Saving useful context is an explicit action. Connecting a tool does not automatically archive conversations or load your entire vault. Each assistant needs a startup instruction and access to the selected notes.

What’s in the download?

The latest source ZIP includes the cloud-first skill instructions, empty templates, contribution rules and local tools. Python 3.10+ is needed for the initializer and validator. The initial v0.1.0 release predates these documentation updates.
