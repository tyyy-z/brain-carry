Engram Cloud stores the shared notes. Connect each supported assistant so it can read and update them, even while your computer is off.

Obsidian lets you read and edit those notes on your devices. A chat sees new information only after it reads the updated notes.

Choose what to save and which services may access it. Your notes use Markdown, a plain-text format you can open in an editor.

GitHub is only an optional manual backup. Shared notes do not change a model’s built-in memory.

Useful answers.

Is this a new notes app?

BrainCarry is an Agent Skill: reusable instructions that help an AI work with your notes. It includes blank templates and optional local tools. You keep using your own editor.

What can I use it for?

Interview practice, a study plan, a side project or recurring writing. Save your preferences, useful notes and next steps so another connected assistant can continue.

Do I need a cloud service?

Use Engram Cloud + Obsidian if connected assistants need access while your computer is off. You can also keep everything local; local access then needs that computer online. BrainCarry itself does not host your notes.

Will it remember every chat?

No. Ask it to save the details you want to keep. Each assistant needs permission to read and update the shared notes; connecting a tool does not save every conversation.

What’s in the download?

The latest source ZIP includes the cloud-first skill instructions, empty templates, contribution rules and local tools. Python 3.10+ is needed for the initializer and validator. The initial v0.1.0 release predates these documentation updates.
