# Workflows

## Ingest

Preserve a dated source record in [raw](raw/README.md); read existing targets; extract supported claims; update relevant [wiki](wiki/README.md) or profile pages; link evidence; update [index](index.md) when navigation changes; append [log](log.md). Import personal records only within the user's requested scope.

## Cloud write → other agent read

When authorized, update the relevant Markdown note directly in the selected shared cloud vault, keeping provenance and conflict safeguards. Another connected agent must explicitly retrieve that note to see the latest state; neither its current conversation nor its built-in memory updates automatically. Obsidian's role is to sync/edit the same supported notes on devices. GitHub is for manual backup only.

## Query

Read only relevant context and evidence. Cite sources. Ordinary chat is not automatically saved. Save durable synthesis within the user's authorized scope.

## Concurrent contributions

One semantic writer per canonical page. If ownership is unknown, write a unique proposal into [inbox](inbox/README.md), with the proposed target, source and uncertainty. A designated editor merges after rereading. Text merges do not resolve contradictory facts.

## Lint and backup

Validate links and scope; manually review stale or contradictory claims. Git backup is manual and requires an explicit request. Do not create background jobs or automatically push changes.
