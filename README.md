# BrainCarry website

Public site: https://tyyy-z.github.io/brain-carry/

This branch contains only the static website. The skill, tests and release instructions live on [main](https://github.com/tyyy-z/brain-carry).

Edit index.html for copy, site.config.js for current download/version links, styles.css for appearance, and script.js for the synthetic interactive example. All assets are relative; no build is needed. Open index.html locally, or serve this directory with a local HTTP server.

GitHub Pages publishes this branch's root. See [website maintenance](https://github.com/tyyy-z/brain-carry/blob/main/docs/website.md).

Cabinet Grotesk attribution and source: [assets/FONTS.md](assets/FONTS.md). The Project Lattice example is fictional. No private vault data is included.
