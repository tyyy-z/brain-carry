开始前，先了解。

这是新的笔记应用吗？

BrainCarry 由 Agent Skill（智能体技能）、Markdown 模板和本地 Python 工具组成，为你已有的助手提供维护个人背景和共享知识的流程。你可以继续使用自己的编辑器。

一定需要云服务吗？

如果希望电脑关机时多个助手仍能访问笔记，推荐使用 Engram Cloud + Obsidian。每个客户端都需授权并验证读写。也支持纯本地 Markdown，但读取本地文件需要电脑可用。BrainCarry 本身不提供同步服务器。

会自动保存所有聊天吗？

保存有用的上下文是一项明确操作。连接工具不会自动归档所有聊天，也不会加载整个知识库。每个助手都需要启动指令，以及所选笔记的访问权限。

下载包里有什么？

最新源码包包含云优先 skill 说明、空白模板、协作规则和本地工具。初始化与验证工具需要 Python 3.10+。最初的 v0.1.0 release 早于这次文档更新。
