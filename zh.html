这是新的笔记应用吗？

BrainCarry 是一个 Agent Skill（智能体技能）：一套可重复使用的指引，让 AI 知道怎样维护你的笔记。它附带空白模板和可选本地工具，你仍然使用自己的编辑器。

哪些场景适合用？

面试练习、学习计划、个人项目，或持续写作。把偏好、有用的笔记和下一步保存下来，让另一个已连接的助手接着帮你。

一定需要云服务吗？

如果希望电脑关机时，已连接的助手仍能访问笔记，可以使用 Engram Cloud + Obsidian。也可以全部保存在本地，但访问时需要那台电脑在线。BrainCarry 本身不托管笔记。

会自动保存所有聊天吗？

不会。你需要明确要求保存哪些内容。每个助手都需要共享笔记的读写权限；连接工具不等于自动保存所有对话。

下载包里有什么？

最新源码包包含云优先 skill 说明、空白模板、协作规则和本地工具。初始化与验证工具需要 Python 3.10+。最初的 v0.1.0 release 早于这次文档更新。
